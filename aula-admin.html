Activar gestión de BCPOL

Para proteger los datos de los alumnos, cambia primero la contraseña de bcpol. No cambia ninguna contraseña de los alumnos.

1. Abre el editor SQL privado de BCPOL en Supabase.

2. Ejecuta la consulta select bcpol_private.aula_issue_code(); y copia el código que aparezca como resultado.

3. Introduce abajo tu contraseña actual, la nueva y ese código de un solo uso (válido durante 24 horas).

No compartas la contraseña ni el código por chat. Esta consulta solo puede ejecutarse desde el editor privado del proyecto.

Mínimo 8 caracteres, con mayúsculas, minúsculas, números y un símbolo.

La activación cierra todas las sesiones actuales de bcpol. Después deberás iniciar sesión con la nueva contraseña.

1. Datos del alumno

El alumno debe autorizarse en Drive por separado.

2. Acceso por mensualidad

Un mes abonado se conserva indefinidamente. Si el alumno causa baja, no desmarques meses anteriores. «Drive verificado» se marca solo tras confirmar que el correo tiene permiso para la carpeta correspondiente.

3. Registrar una clase

Las carpetas no se publican por defecto. Se recomienda una carpeta independiente por mensualidad, sin heredar permisos de una carpeta general compartida.

4. Vídeos de YouTube por clase

Selecciona una clase ya registrada y pega el enlace de su grabación. El enlace aparecerá en el Aula Virtual únicamente a los alumnos con acceso a esa mensualidad. No modifica las carpetas ni los pagos.

Deja el campo vacío y guarda para quitar el vídeo. Los vídeos privados requieren permisos de YouTube aparte.
